# OpenAPI Contract Property Tester

An autonomous engineering skill for the `qa-tdd-engineer` agent designed to perform property-based boundary testing and structural contract validation against OpenAPI specifications.

## Features
- **Boundary Synthesis:** Automatically computes edge-case values for numeric bounds, string lengths, and array item constraints.
- **Contract Assurance:** Detects specification mismatches and ensures robust payload verification.
- **Zero-Dependency Core:** Implemented purely in Python 3 Standard Library for maximum portability.

## Quick Start
```bash
python3 workflow.py
```
