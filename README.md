# 🤖 AI Agent Workforce & Curated Skills

A modular, production-ready roster of specialized AI agents. Each agent maintains a dedicated kit of actionable skills, workflows, and prompts designed for autonomous coding environments (Antigravity, Cursor, Claude Code, OpenAI Swarms, LangChain/CrewAI).

---

## 👥 The Agent Roster

| Agent Identifier | Focus Area | Core Competencies |
| :--- | :--- | :--- |
| **`backend-architect`** | System Design & Resilience | Distributed caching, circuit breakers, sharding, event-driven pipelines. |
| **`security-auditor`** | AppSec & Vulnerability Audit | Static taint analysis, prototype pollution, dependency CVE remediation, secret scanning. |
| **`root-cause-debugger`** | Diagnostic Investigation | Memory leak heap dumps, deadlock analysis, flaky test isolation, regression bisect. |
| **`clean-code-reviewer`** | Refactoring & Code Quality | SOLID principles, design patterns, cyclomatic complexity reduction, code simplification. |
| **`devops-sre`** | Infrastructure & CI/CD | Docker multi-stage builds, self-healing GitHub Actions, Kubernetes configurations. |
| **`qa-tdd-engineer`** | Test-Driven Development | Edge-case generation, contract verification, Vitest/Jest suites, benchmark testing. |
